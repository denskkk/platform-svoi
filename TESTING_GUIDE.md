# Запуск и тест обновления «соцсеть + экосистема»

Ветка: `feature/social-feed`. В `main` ничего не вливать и на прод не выкладывать до результатов теста.

## 0. Перед стартом (одноразово)
```bash
# Сделайте бэкап БД (миграции только добавляют, но бэкап обязателен)
pg_dump "$DATABASE_URL" -Fc -f backup_$(date +%F).dump

# На сервере: ffmpeg для видео и swap для сборки (1 CPU / 4 ГБ)
sudo apt update && sudo apt install -y ffmpeg
ffmpeg -version | head -1 && ffprobe -version | head -1
sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
free -h
```
Продлите VPS (оплачен до 22.11.2026).

## 7. Сценарии ручного теста (по ТЗ)
Нужны 3 аккаунта: **A** (обычный), **B** (будет бизнесом), **Admin**.

1. **Регистрация:** `/auth/register` → имя, фамилия, email, пароль → сразу `/feed`. Гость на `/` видит новый лендинг; вошедший перекидывается в ленту.
2. **Лента:** пост с текстом и фото; лайк, комментарий, ответ на комментарий, лайк комментария; подписка A→B; закладка.
3. **Видео:** композер → «Відео» → mp4 до 50 МБ → статус «Обробка відео…» → готово → опубликовать. В ленте плеер, перемотка работает. Файл >50 МБ и неверный формат дают понятную ошибку. `/video` — вертикальная лента, автозапуск, лайк.
4. **Истории:** над композером «+» → фото или видео → кружок появляется у подписчиков (A видит историю B) → просмотр → счётчик просмотров у автора → удаление.
5. **Поиск:** `/search` → текст; фильтр «Місто» и «Напрям»; вкладка «Клуби».
6. **Бизнес:** B → `/business/apply` (процент выбрать из чипов) → Admin → `/admin/business-applications` → одобрить → у B появилась карточка компании, страница `/companies/<id>`.
7. **Организация:** `/organizations/apply` → Admin одобряет в `/admin/organization-applications`.
8. **Проекты:** `/projects` → авто/недвижимость/здоровье/спорт/магазины/события: создать объявление → модерация (Admin) → публикация. В «Магазинах» кнопка «Перейти до магазину» ведёт на сайт магазина.
9. **Клубы:** `/clubs` → создать → второй аккаунт вступает/выходит.
10. **Реферальная программа:** Admin → `/admin/deals` → вкладка «Програми» → активировать для B (процент, номер договора). A на `/companies/<id>`: «Скопіювати моє посилання» / «Передати клієнта». B → `/business/clients` → подтвердить сделку с суммой. Admin → `/admin/deals`: «Нарахувати», затем «Відмітити виплату». A → `/earnings` видит суммы и историю. Проверить: нельзя создать сделку с собственной компанией, дубль клиента отклоняется, после подтверждения сумма не меняется, спор открывается из `/earnings` и `/business/clients`.
11. **Уведомления:** по каждому шагу выше приходит уведомление, переход по нему открывает правильную страницу.
12. **Языки:** переключить uk/en — нет «сырых» ключей вида `feed.xxx`.
13. **Новое в последнем обновлении:** репост и реакции (долгое нажатие на «Подобається»); `/business/stats`; `/companies/<id>/qr` (скан телефоном, скачать SVG); ⚙ на странице уведомлений (выключить группу и убедиться, что колокольчик не считает её); `/admin/partners` → вкладка контента: видео-ссылка, шаги, примеры → страница `/projects/<slug>/earn`; в заявке бизнеса логотип, банер, «Використати моє місцезнаходження»; обложка профиля (кнопка «Змінити обкладинку»); `/admin/roles` → роль «Адміністратор».
14. **Мобильное приложение (Capacitor):** тот же набор на телефоне, особенно загрузка видео и нижнее меню. Приложение грузит сайт, пересборка не нужна, пока не меняется нативная часть.

## 8. Что смотреть в логах при проблемах
