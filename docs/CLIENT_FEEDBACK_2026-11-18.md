# Замечания заказчика 18.11.2026 → ТЗ → статус

Источник: транскрипт голосовых + переписка + 5 скринов меню TikTok (документ «Замечания заказчика»). Ветка `feature/social-feed`.

## 3. Настройки
Личные и бизнес-настройки раздельно. Работает на сервере (не только в интерфейсе):
- приватный аккаунт (посты видят только подписчики);
- кто может комментировать / писать в чат (все / друзья / никто);
- бизнес: «клиенты могут писать мне»;
- контакты (телефон, e-mail) скрыты по умолчанию; адрес и личные данные чужим не отдаются никогда;
- запись/показ просмотров профиля;
- бизнес-таргетинг (пол, возраст, страна/область) и «что показывать в ленте» (область/страна) — **сохраняются**, но ещё не влияют на выдачу (нужна рекламная система — отдельный этап).

## 4. Профиль/кабинет
Подписчики, подписки, лайки (для всех); запрошені и угоди (только владельцу); звезда «Активний учасник» (запросил ≥1 человека и ≥1 завершённая сделка; пороги в `src/lib/invites.ts`).

## 5. Проекты
- «Таксі» — первый проект: «Замовити таксі» и карта — заглушка «в доопрацюванні», «Подати заявку таксистом» (форма партнёра), «Заробляти зі своїми».
- Тематические «шпалери» у каждого проекта, синяя «космическая» гамма + жёлтые акценты (`src/lib/projectThemes.ts`).
- Внизу «Офлайн бізнес» (город/карта) и «Онлайн бізнес» (поиск).
- «Автомобілі» → «Автосалони»; добавлены «Адвокатські об’єднання».
- ❓ Названия проектов: заказчик говорит, что названия придуманы им, но полного списка в материалах нет. Нужен список → правится в `/admin/projects` без кода.

## 6. Цвет
Бежевая палитра заменена на холодную сине-серую; нижнее меню тёмно-синее с жёлтым; шапка с жёлтой линией. Дальше — полировка по видео заказчика.

## 7. Безопасность (найдено при разборе)
`GET /api/profile/<id>` отдавал любому, даже без входа, e-mail, телефон, детей, авто и т. п. Исправлено: чужим — только публичные поля.

## 8. Не сделано / нужны решения
Эфиры (сервис стриминга), реальный заказ такси (диспетчеризация, карты), кошелёк и подарки (платёжный провайдер, юр. условия), реклама по таргетингу, семейный кабинет, push.
