4. Картки/плитки без емодзі-«стікерів», сучасний вигляд.

## Ризики, які НЕ закриті (рішення за власником)
- У репозиторії лежать профілі підписання iOS (`ios_code_signing/*.mobileprovision`, `.certSigningRequest`) і старі `.ipa` (`ios_distribution/binaries`). Це не приватні ключі, але гігієнічно варто винести з git (окремий PR після викладки).
- Не перевірено автоматично: `npm run build`, `tsc`, реальні запити до БД (нова схема Negotiation/NegotiationMessage), Capacitor-збірка.
- Фото Pixabay — заглушки: ліцензія дозволяє комерційне використання без атрибуції, але для головних екранів варто замінити своїми; на фото людей немає гарантії model release.
- Інтерактивної карти (піни), автоперевірки реєстру агрохімікатів, адмін-перегляду переговорів, LIVE, інших мов окрім uk/en — немає (відомі обмеження).

## Порядок викладки (виконується лише після явного «так»)
1. Локально: `git pull`, `.\scripts\local-update.ps1`, `npm run build` — зелений, швидкий ручний прогін (реєстрація → вибір мови, стрічка, «+» студія, проєкти, альянс: форма → кабінет → переговори, адмінка: картинки папок).
2. GitHub: PR `feature/social-feed` → `main`, перегляд, merge.
3. VPS: `pg_dump` резервна копія → `git pull --ff-only origin main` → міграції 20261142–20261154 по черзі (`psql -f`) → `npx prisma generate` → `bash scripts/deploy.sh`.
4. Картинки папок/банерів з локалки: `scripts\export-folder-images.ps1` → на VPS `bash scripts/import-folder-images.sh`.
5. Застосунок: `npm run build:mobile`, Android Studio → Build → Generate Signed Bundle (versionCode 5), Xcode → Archive (build 9). Перевірити камеру й мікрофон на реальному пристрої.
